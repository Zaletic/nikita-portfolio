# Nikita Bangia — Portfolio

Static portfolio site, deployed on Vercel.

- `build.mjs` generates every page: `node build.mjs`
- `css/style.css`, `js/main.js` hold the styling and interactions
- Placeholder to replace in `build.mjs`: `SITE.email`, `SITE.linkedin`, `SITE.instagram`

Local preview: `node serve.mjs` then open http://localhost:5300
